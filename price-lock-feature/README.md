# Price Lock Feature 

## Overview
Price Lock is a feature allowing users to hold a flight ticket price for a certain period (24–72 hours) by paying a small fee. This helps customers avoid price fluctuations and make more confident purchasing decisions.

## Problem
Flight prices fluctuate frequently, causing customers to hesitate in completing bookings. This uncertainty results in lost revenue and poor user satisfaction.

## Solution
Introduce a Price Lock feature that allows customers to reserve a price temporarily while they finalize their travel plans.
